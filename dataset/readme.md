## ReasonSeg-Hard
We have 79 Images in this dataset most are sampled from ReasonSeg-Test, the dataset can be downloaded from
[this link](https://drive.google.com/file/d/1rPLPF_Ftk-YHXLvBpowy_aSpBMlu2fDp/view?usp=drive_link).

If you read the dataset using the class provided in read_dataset.py, entries will be in the format of
(img_name, query, mask_name).
